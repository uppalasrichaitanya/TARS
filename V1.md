## Post-tag verification

- Tab completion originally failed because the REPL used `sys.stdin.readline()`,
  which bypasses Python readline completion. The real interactive path now uses
  `input()`, with explicit space/tab/newline delimiters. A PTY smoke expanded
  `/ver<Tab>` to `/verify`; injected streams remain unchanged for tests.
- `pipx` was installed and tested. `pipx install tars-agent` by name now
  succeeds (published as `tars-agent 0.1.0` at `https://pypi.org/project/tars-agent/0.1.0/`
  with `Author: TARS contributors <uppalasrichaitanya2007@gmail.com>` and corrected
  `Repository: https://github.com/uppalasrichaitanya/TARS`). The installed
  distribution exposes all five applications (`tars`, `tars-browser`,
  `tars-memory`, `tars-readme`, `tars-verify`) and `tars --version` returns
  `0.1.0`. `python -m build` + `twine check` now PASSED (no warnings) after
  adding `readme = {file="README.md"}`. The prior published-name limitation is
  closed as of `v0.1.0` (`08cfb6b`).
- The live run first requested `apply_edit` with `kind: "anchored"`. At the time,
  the parser accepted only `replace`, `create`, `overwrite`, and `delete`, so the
  call returned an ordinary tool error and made no write. The model then made a
  successful gated `apply_edit` before running commands; the one-shot transcript
  was not persisted, so whether it omitted `kind` or used `replace` cannot be
  recovered exactly. `anchored` is now an explicit alias for the same safe
  anchored-hunk replace path, including dry-run, diff, confirmation, and unique
  anchor enforcement.

These corrections are committed after the original `v1` tag. The tag is not
silently moved; it remains an immutable marker of the initial v1 close-out.
